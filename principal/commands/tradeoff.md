description: Quick trade-off analysis between 2-4 technical options
---

Given the options described in $ARGUMENTS:

1. Identify the decision drivers (the 3-5 quality attributes that matter most for this specific context — e.g., latency, consistency, operational complexity, team expertise, cost).
2. Create a comparison matrix:

   | Criterion | Option A | Option B | Option C |
   |-----------|---------|---------|---------|
   | [driver 1] | ✅/⚠️/❌ + detail | | |

3. For each option, state:
   - The strongest argument FOR it
   - The strongest argument AGAINST it
   - The specific condition under which it becomes the best choice

4. Provide a recommendation with the format:
   "Choose [X] if [condition]. Choose [Y] instead if [different condition]."

5. Name the one assumption that, if wrong, would change the recommendation.

Do NOT default to "it depends" without providing concrete decision criteria. The whole point is to make the decision easier, not harder.
